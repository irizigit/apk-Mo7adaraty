## التطبيق

1. يقرأ التطبيق رقم البناء الأصلي عند التشغيل.
2. يجلب `version.json` بمهلة زمنية قصيرة ولا يمنع عرض الواجهة عند فشل الشبكة.
3. عند وجود إصدار أحدث، تظهر نافذة تحديث تتضمن سجل التغييرات وزر فتح صفحة التنزيل.
4. عند جعل التحديث إلزامياً، يمكن متابعة استخدام البيانات المحلية لكن لا يسمح بإغلاق نافذة التحديث قبل فتح صفحة التنزيل.
