# محاضراتي نوفا

تطبيق أندرويد عربي حديث لتنظيم المقررات والمحاضرات والملفات والملاحظات، مع واجهة RTL مخصصة لتسهيل التركيز والمتابعة اليومية.

## الخصائص المتاحة

| المجال | ما يتضمنه التطبيق |
|---|---|
| إدارة الدراسة | مقررات، محاضرات، مرفقات، نسب إنجاز، وخطة المحاضرة التالية |
| الملاحظات | إنشاء، بحث، تثبيت، وحذف ملاحظات الدراسة |
| الملفات | استيراد ملفات PDF، الفيديو، الصوت، والملفات النصية إلى أي مقرر |
| التحفيز | ملخص أسبوعي، تقدم لكل مقرر، وعدّاد المحاضرات المنجزة |
| الخصوصية | واجهة إعدادات لقفل الملاحظات وتذكيرات الدراسة |

## التشغيل محلياً

يتطلب المشروع Node.js 20 أو أحدث وpnpm 9. بعد فك الضغط، شغّل الأوامر التالية:

```bash
pnpm install
pnpm dev
```

بعد بدء الخادم، امسح رمز QR عبر Expo Go على أندرويد أو استخدم معاينة الويب. لبناء مشروع Android محلياً:

```bash
npx expo prebuild --platform android
cd android
./gradlew assembleDebug
```

ينتج ملف APK هنا:

```text
android/app/build/outputs/apk/debug/app-debug.apk
```

## البناء عبر GitHub Actions

يحتوي المشروع على ملف `.github/workflows/build.yml`. بعد رفع المشروع إلى GitHub، سيبني هذا الملف APK تلقائياً عند الدفع إلى فرع `main` أو `master`. يمكن تنزيل ملف APK الناتج من قسم **Actions** ثم **Artifacts** في GitHub.
